# 総務アシスタント（総務向け）利用マニュアル

**BrightStar 統合 LINE アシスタント — 総務チャネル**
対象：総務担当者 / 版本：v1.2 / 最終更新：2026-08-21
LINE 表示名：**BS総務**（2026-08 にアカウント名を BS◯◯ 形式へ統一）

> 本チャネルは **総務担当 専用** です。勤怠（勤務表）・通勤費（経費）の **提出状況の確認・未提出の抽出・催促・一括ダウンロード** を行います。
> 社員からの提出そのものは「BS社員管理」が受け付けます。本チャネルは**受領は行わず**、管理・集計・督促に専念します（責務分離）。
> 中文：本窗口仅限**总务**使用；负责考勤(勤務表)·通勤费(经费)的**提交状况确认/未提交筛选/催促/打包下载**。员工提交请用「BS社員管理」。

---

## 1. はじめに（毎日の本人確認）

人事・勤怠情報を扱うため、**毎日（東京時間）最初の利用時に本人確認**が必要です。

### 1-1. 初回登録（最初の1回だけ）
```
総務部 高橋 茉鈴
```
- 社員名簿と照合し、**役割が 総務（soumu）または 人事（hr）** の本人のみ登録できます。
- 同姓同名は社員番号を付与：`総務部 高橋 茉鈴 S001`
- 一度登録すると LINE アカウントと社員番号が**専用に紐付き**ます（1人＝1社員番号）。

### 1-2. 毎日の認証
2日目以降は **「認証」** ワンタップ（またはメニューの「本日認証」）でその日の確認が完了します。

### 1-3. 言語の選択
認証後、最初に **「日本語」／「中文」**（既定：日本語）。後から「日本語」「中文」で切替可。

### 1-4. 登録のやり直し
**「登録解除」** で紐付けを解除し、別人で登録し直せます。

## 2. コマンド一覧

| 操作 | 主なキーワード | 内容 |
|------|---------------|------|
| ヘルプ | `ヘルプ` / `菜单` | 機能とキーワードをボタン表示 |
| 提出状況の確認 | `一覧` / `提出状況` / `提交情况` | 全社員の提出状況（未提出を上に） |
| 未提出者の確認 | `未提出確認` / `未提出` / `未提交` | 未提出者だけを抽出 |
| 催促（リマインド） | `催促` / `リマインド` / `催办` | 未提出者へ LINE 通知を送信 |
| **催促予約** | `催促予約`（→日時ピッカー） | 指定日時に自動で催促（2026-07 追加） |
| 予約の確認/取消 | `予約確認` / `予約取消 <ID>` | 予約中の催促の一覧・取消 |
| **手動「済」** | 未提出確認の**ボタンをタップ** / `済 氏名` / `済解除 氏名` | メール等受領者を催促対象から除外 |
| 一括ダウンロード | `一括DL` / `打包下载` | 当月の全提出を ZIP でDL（他の月はボタンで選択） |
| 個別ダウンロード | `個別DL E003 E004` | 選んだ人だけ ZIP でDL |
| **未提出CSV** | `未提出CSV[YYYYMM]` | 未提出者一覧を表計算(CSV)で出力（人数が多いとき用） |
| **提出物の削除** | `削除 氏名 勤務表` | 不備ファイルを取り消し、本人へ再提出依頼を自動送信 |
| **確認状況** | `確認状況 [ID]` | 催促/一斉送信の既読(確認)状況＋CSV |
| **一斉送信** | `一斉送信`（管理者のみ） | 全社員へお知らせを配信（2026-07 追加） |
| 本日認証 | `認証` / `本日認証` | その日の本人確認 |
| 登録解除 | `登録解除` | 別人で認証し直す |

> 多くのコマンドは **月指定**が可能です（例：`未提出確認 202606`、`一括DL 202606`）。省略時は当月。
> 対象は **勤怠（勤務表）** と **通勤費（経費）** の2種類です。

## 3. 操作の詳細

### 3-1. 提出状況の確認
> 🔢 一覧の先頭に **合計／提出済／未提出の人数**、各行に **①②③…の連番**が付きます。
> 📅 提出の受付は**前月・当月**分。翌月頭にずれ込んだ前月分も、**ファイル記載の年月**のフォルダ・月に計上されます（8月提出の7月分 → 7月の「提出済」になります）。
- `一覧` … 全員の提出マトリクス（✓＝提出済 / ✗＝未提出）。件数が多い場合は分割して送信します。
- `未提出確認` … 未提出者の氏名・部署・未提出の種別を一覧。
- いずれも末尾に `202606` のように月を付けると過去月を確認できます。

### 3-2. 催促（リマインド）
```
催促            ← 当月の未提出者へ
催促 202606     ← 月を指定
```
- 未提出者にだけ LINE 通知が届きます（提出済の人は自動で除外）。
- 通知文例：
  ```
  お疲れ様です😊
  2026-07 の勤務表が、まだ届いていないようです。
  お手すきの際にご提出をお願いします🙏
  既に提出済みでしたらご容赦ください！
  ```
- メッセージには **「✅ 確認しました」ボタン**が付き、既読状況を `確認状況` で集計できます（3-2g）。
- **毎月25日・28日 9:00（JST）に自動でも催促**が送られます（手動催促と併用）。
- 📌 リマインドは **「BS社員管理」から社員へ届きます**（総務が催促を実行・確認し、通知は社員側のトークに表示）。総務担当には実行結果の件数のみ返ります。
- ⚠️ 社員が **「BS社員管理」を友だち追加**していない／LINE未登録 の場合は通知が届きません（一覧には表示。総務担当が個別連絡）。

### 3-2b. 催促予約（日時を指定して自動催促／2026-07 追加）
```
催促予約        ← 日時ピッカーが開く
予約確認        ← 予約中の一覧（ID付き）
予約取消 a1b2c3 ← ID を指定して取消
```
1. メニューの **「催促予約」** をタップ → LINE の**日時選択画面**が開きます（明日 9:00 が初期値、60日先まで）。
   💻 **PC 版 LINE で時刻が選びにくい場合**は、`催促予約 2026-07-25 09:00` のように**日時を直接入力して送信**してもOKです（`7/25 9:00` の短縮形も可）。
2. 日時を選ぶと予約完了：`⏰ 催促を予約しました：2026-07-20 09:00（ID: a1b2c3）`
3. 予約時刻から **10分以内**に自動実行され、**その時点で未提出の人だけ**に届きます（提出済・手動「済」の人は対象外）。

### 3-2c. 手動「済」＝催促の対象から外す（2026-07 追加）
メール等で既に受け取っている人を、手動で「提出済み扱い」にできます（LINE未登録の社員にも使えます）。

**いちばん簡単な使い方（ボタン）**：
1. `未提出確認` を実行すると、一覧の下に **種別ごとの「済」ボタン**が表示されます（例：`済 山田太郎(勤)`＝勤務表だけ／`済 山田太郎(経)`＝経費だけ。先頭13件分）。
2. メール等で受領済みの**種別のボタンだけ**をタップすれば、その種別のみ催促対象から外れます（もう一方は引き続き催促されます）。

コマンドでも指定できます（**氏名でも社員番号でも可**。一覧の行頭に社員番号が表示されます）：
```
済 山田太郎        ← 勤怠・経費の両方を済に
済 E003 勤怠      ← 社員番号＋種別指定
済解除 山田太郎    ← 取り消し
```
- 済にした人は `未提出確認`・`催促`・自動催促・催促予約の**すべてから外れます**。
- `一覧` では **✓(手)** と表示され、誰がいつ済にしたかも記録されます（監査用）。
- 14人目以降は「済 氏名」を送信して指定してください。

### 3-2d. 一斉送信（全社員へのお知らせ配信／2026-07 追加・管理者のみ）
メニューの **「一斉送信」** から、全社員への一斉連絡（お知らせ）を配信できます。

1. **「一斉送信」** をタップ → **「✏️ 入力フォームを開く」ボタン**が届きます
2. ボタンを押すと**入力フォーム（テキストボックス）**が開きます。内容を書いて **「📨 全社員に送信する」** をタップ（対象人数と確認ダイアログが表示されます）
3. 配信開始。完了後に LINE へ「成功◯名／失敗◯名」の結果が届きます
   - フォームを使わず、そのままトークに内容を送信してもOK（プレビュー→「送信する」で確定）。「キャンセル」で中止。
   - フォームのリンクは **30分有効**（切れたら「一斉送信」をもう一度）。

- 📌 お知らせは **「BS社員管理」のトークから全社員へ届きます**（催促と同じ経路）。
- 対象は **LINE連携済みの全社員**（未連携・ブロック中は対象外。人数はプレビューに表示）。
- **権限**：花名册で「管理者」フラグのある人だけが使えます。付与は人事アシスタントで：
  ```
  社員変更 E001 管理者 true      ← 付与
  社員変更 E001 管理者 false     ← 解除
  ```

### 3-2e. 未提出者を表計算(CSV)で出す（2026-08 追加）
人数が多いとチャット表示では見づらいため、CSV で出力できます。
```
未提出CSV            ← 当月
未提出CSV 202607     ← 月を指定
```
- `未提出確認` の下に出る **「📄 CSVで出す」** ボタンからも同じことができます。
- 列：No／社員番号／氏名／部署／属性／未提出の種別／LINE連携／対象月（Excel でそのまま開けます）

### 3-2f. 提出物の削除（2026-08 追加）
内容に不備があった提出を、総務が取り消せます。
```
削除 山田太郎 勤務表          ← 確認ボタンが出る → 「🗑 削除する」で確定
削除 E003 交通費 202607       ← 社員番号・月の指定も可
```
- 削除すると **本人の社員アシスタントに「再提出のお願い」が自動送信**されます。
- 削除後は「未提出」に戻るため、通常どおり催促の対象になります。

### 3-2g. 既読(確認)状況の把握（2026-08 追加）
**催促・催促予約・一斉送信**で送るメッセージには **「✅ 確認しました」ボタン**が付きます。
- 社員がタップすると、確認済みとして記録されます。
- 総務は `確認状況` で件数を確認できます（`確認状況 <ID>` で過去分も）。
```
確認状況              ← 直近の配信
確認状況 a1b2c3       ← ID 指定（配信完了時に通知される ID）
```
- 表示：`対象 ◯名：確認済 ◯名 ／ 未確認 ◯名` ＋ **CSVダウンロード**（誰が未確認かの一覧）

### 3-3. 一括ダウンロード／個別ダウンロード
```
一括DL                 ← 当月の全提出を ZIP で
個別DL E003 E004       ← 選んだ人だけ ZIP で（社員番号でも氏名でも可）
個別DL 山田太郎 202606  ← 月指定も可
```
- ZIP をまとめ、「ダウンロード」ボタンを返します。リンクは署名付きの短縮 URL で、一定時間で失効します。
- 一括DL を実行すると、続けて **他の月を選ぶボタン（直近5ヶ月）** が出ます。`一括DL 202606` と直接指定してもOK。
- 個別DL では、提出が無い人・名簿に見つからない人はメッセージ内に注記されます。

- **社員名簿の管理（追加/変更/削除）** と **メール校正ツール** は **人事アシスタント**側の機能です（総務チャネルにはありません）。

## 5. 参考：社員の提出内容の自動チェック

社員が提出すると、システムが内容を自動チェックします（提出の受領は「BS社員管理」）。一覧で不備を確認・案内する際の参考にしてください。

**交通費経費**
- ❌ アップロード不可：対象年月(B1)が前月・当月以外／氏名(D6)が登録名と不一致（簡体字・繁体字どちらでもOK）／**出勤状態(D列)に未記入の日がある**（その月の全日に 出勤/休み/在宅 等を記入必須）／**⑤本人確認のチェックが未チェック**
- 🔔 提出は可だがリマインド：責任者氏名(D7)が未記入・「（本社メンバーの名前）」のまま（定期券購入時は記入必須）／提出成功時「定期券は写真添付必須」

**勤務表（勤怠）** ※2026-08 様式変更に伴い**内容チェックは廃止**
- 自動チェックは行わず、そのまま受け付けます（内容は総務・担当者が目視で確認）。
- 保存先の年月は様式内の年月（J1年／L1月）で自動判定。読めない場合は提出した月に格納します。

## 6. よくある質問

**Q. 社員が送った Excel をこの窓口に転送できますか。**
できません。提出は社員アシスタントが受領します。総務チャネルは管理・集計・催促用です。

**Q. 催促を送ったのに届かない人がいます。**
その人が **総務アシスタントを友だち追加**しているか、LINE の通知設定をご確認ください。提出済の人にはそもそも送られません。

**Q. 自分の名前で認証できません。**
所属部署＋氏名（例：`総務部 高橋 茉鈴`）で入力してください。全角/半角・かなの違いは自動で吸収します。同姓同名のときは末尾に社員番号（例 `S001`）。
