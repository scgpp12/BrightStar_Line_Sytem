## 未実施のテスト

**脆弱性検査（SAST / DAST）およびペネトレーションテストは実施していない。**
実施済みのテストは機能面の単体テスト・結合テスト（AWS をモックしたオフラインテスト）のみ。

検査を行う場合の候補：`bandit`（Python 静的解析）／`npm audit`（CDK 依存）／`cdk-nag`・`checkov`（IaC 検査）／AWS Security Hub・GuardDuty。
